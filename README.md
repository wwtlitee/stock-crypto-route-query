# TradeRoute 股票加密入口查询

一个静态网页工具，用于查询美股/ETF 标的在加密平台、RWA App、钱包聚合入口和股票永续平台中的入口覆盖情况。

## 功能

- 输入股票代码或名称，查看加密领域入口覆盖。
- 展示股票基础信息、相关代币符号、链覆盖和平台状态。
- 区分代币化股票、股票永续、钱包入口、发现入口、待核验和未覆盖状态。
- 平台结果使用真实 logo，并提供平台/产品入口链接。

## 本地打开

直接用浏览器打开 `index.html` 即可。

## 数据

当前数据来自本地快照 `assets/market-data.js`，由 `pdoc/script/SCRIPT_generate_market_data.js` 生成。正式上线前建议接入后端定时同步和平台 adapter。
